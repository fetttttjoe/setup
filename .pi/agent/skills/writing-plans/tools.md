# Pi tools

Map of plan-authoring phases to pi affordances.

| Phase | Pi tool | Purpose |
|---|---|---|
| Collect missing decisions | `questionnaire` | Resolve ambiguity before drafting — one focused Q with options |
| Research gate | `read` / `grep` / `find` / `ls` | Investigate before committing to a path |
| Identify files touched | `grep` / `find` | Enumerate every file the plan will modify |
| Verification matrix | `bash` | Confirm the verify-commands actually exist / run in this repo |
| Emit plan (if requested) | `write` | Save plan as a persistent deliverable artifact |
