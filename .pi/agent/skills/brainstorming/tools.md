# Pi tools

Map of the 3-step brainstorming process to pi affordances.

| Phase | Pi tool | Purpose |
|---|---|---|
| Step 1 — understand intent | `questionnaire` | 1–3 focused Qs with concrete options + a "Recommended" default |
| Step 2 — surface decisions | `questionnaire` | One question per axis (storage, trigger, scope, failure mode) |
| Step 3 — locate the change | `read` / `grep` / `find` | Confirm where the change lands and which files it touches |
| Step 3 — record agreed design | `write` (optional) | Persist the agreed design as a doc if the user wants it kept |
